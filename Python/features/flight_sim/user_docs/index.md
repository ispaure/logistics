# Apply X-Plane 12 presets

Flight Simulator exposes X-Plane preset actions on **Debug**. The current workflow
targets the Steam X-Plane 12 installation on macOS and specific display setups.

## Before applying a preset

Supply the expected preset files beneath `Software/General/`. They are private
resources and are not downloaded by the public software manifest. Keep a copy of
your existing X-Plane preferences before replacing them.

## Apply

Choose the Debug preset matching your intended machine/display layout. It copies
settings into X-Plane's active `Output/Preferences` folder under the Steam install.
Missing presets or an unsupported installation can fail; these actions are not a
general cross-platform simulator configuration tool. Verify the result in X-Plane
and restore your saved preferences if necessary.
