# Personal Links on mobile

Personal Links has no mobile page or settings adapter in the current app. Its
configured desktop shortcut catalog is not synchronized to iOS or Android.
Use your device's browser to open a service URL directly.

The **Links** drawer in Notes Library is a separate feature for note connections;
see the [Notes Library mobile guide](../../notes_library/user_mobile/user_mobile.md).
For the desktop shortcut launcher, see the [desktop guide](../user/user.md).
