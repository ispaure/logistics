# Open configured service shortcuts

Enable **Personal Links** in **Settings → Features** and open **Links**.

## Configure shortcuts

In Personal Links settings, edit existing **URLs** keys such as
`plex_common_web_str`, then **Save Settings**. Use Personal Settings for private
addresses. Only HTTP(S) URLs with a hostname are accepted. Under **ResolveIP**,
set `goat-pc_str` or `yagi-mac_str` to a hostname or address to replace
`<goat-pc>` or `<yagi-mac>` in a URL.

## Open a link and troubleshoot

Choose a shortcut to open your browser. If the service fails to load,
check its URL, resolved address and network connection.
