# Obsidian notes on mobile

[Obsidian guides](../obsidian.md)

The desktop Obsidian vault launcher is not a mobile integration. Logistics on
iOS and Android does not update Obsidian's desktop registry or offer the desktop
**Open "VaultName" Vault** workflow.

To use your notes inside Logistics, enable **Notes Library** in
**Settings → Features** and open **Documents → Notes Library**. Discovery finds
local and unlocked LocalCrypt folders containing an `.obsidian` directory at
the storage root or up to two folders below it. Use **Refresh libraries** after
adding or moving a library. Download or sync cloud folders locally first.

Follow the [mobile Notes Library guide](../../notes_library/user_mobile/user_mobile.md)
for Markdown editing, source files, drawings, search, calendar, links and file
organization. Notes Library uses the files in that copy without requiring the
Obsidian application. It does not run Obsidian plugins; its supported
[`dataviewjs` subset](../../notes_library/user/user.md#json-data-views-in-notes-library)
is described separately.
