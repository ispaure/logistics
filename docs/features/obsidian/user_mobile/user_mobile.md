# Obsidian notes on mobile

[Obsidian guides](../obsidian.md)

For local or unlocked LocalCrypt vaults, enable **Settings → Features → Notes Library**, then open **Documents → Notes Library**. Use **Refresh libraries** after adding folders. Download cloud copies locally first. The external vault launcher and Obsidian plugins are unavailable on mobile.
