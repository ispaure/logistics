# Smart Home on mobile

Smart Home controls are currently desktop-only. The Android and iOS Logistics
apps do not include a Smart Home destination, Hue pairing, room discovery or
Tautulli playback automation. Installing the mobile app does not run the desktop
scripts.

Use the [desktop guide](../user/user.md) to configure Hue controls and external
Tautulli scripts. See [implementation and validation](../development/development.md)
for the current packaging boundary; mobile light-control acceptance is not claimed.
