# IDE on mobile

The project IDE is available in the desktop app only. Android and iOS do not
provide IDE project registration, split code-editor groups, Jedi navigation,
Find in Files or IDE Git change-marker review. Desktop IDE layouts and project
registrations are not a mobile workspace or a synchronization mechanism.

For mobile document editing, use the app’s
[mobile guides](../../../user_mobile/user_mobile.md). Those workflows have their
own storage and editing behavior; they do not open a desktop IDE project.
