# Plex on mobile

Plex server backup, restore and database comparison is a desktop workflow. Logistics does not provide
this feature’s management dialog on Android or iOS. The desktop Qt workflow is
not a mobile download, server-management or background-job service.

Use the [desktop guide](../user/user.md) to perform the operation on a desktop.
To play an already available video on mobile, use the separate
[Video Player](../../video/user_mobile/user_mobile.md); playback does not run
this management workflow.
