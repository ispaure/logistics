# Browse Dropbox folders and clean conflicts

## Browse

On desktop, select **Source → Dropbox** in **Workspaces**. With multiple
accounts, choose **Dropbox [Account]**.

## Review conflicting copies

Select a synced folder and open **Conflicting Copies… → Review conflicting
copies**. Keep **Include subfolders** on for a recursive scan. Check the list,
then confirm **Delete reviewed identical copies**. Only unchanged, byte-identical
copies qualify. Deletion bypasses Trash and Dropbox may propagate it. Cancellation
keeps completed deletions.

## Scope and troubleshooting

If the source is missing, configure a local account folder in the Dropbox client.
Review recognizes names containing ` conflicted copy ` inside parentheses.
Reconcile unique edits manually. Changing the folder or scope requires a new scan.
