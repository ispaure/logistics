# Rclone on mobile

Choose a guide for the action you want to take. Saving credentials controls how
you unlock a connection later; choosing Local or LocalCrypt controls how an
offline copy is stored.

## Choose a guide

| Task | Guide |
| --- | --- |
| Import a credential ZIP, unlock a connection, or browse online files | [Remote connections](connections.md) |
| Create and use encrypted offline copies; understand Local versus LocalCrypt | [LocalCrypt](localcrypt.md) |
| Pull, review Push, follow progress, cancel, or choose a collection drive | [Transfers and storage workflows](workflows.md) |

For desktop instructions and developer references, use the
[rclone documentation index](../rclone.md).
