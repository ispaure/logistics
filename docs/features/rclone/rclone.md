# Rclone documentation

Start here for rclone connections, transfers and LocalCrypt encrypted copies.
Credential storage and file storage are separate choices: loading credentials
does not create an offline copy, and locking credentials does not delete one.

## Choose a guide

| Audience and task | Guide |
| --- | --- |
| Desktop: load credentials, browse remotes, review Push/Pull | [Connect and transfer remote folders](user/user.md) |
| Desktop: create, unlock, read or edit encrypted copies | [LocalCrypt on desktop](user/user.md#read-and-edit-a-localcrypt-copy-on-desktop) |
| Mobile: connections, encrypted copies and transfers | [Mobile user guide](user_mobile/user_mobile.md) |
| Developers: code ownership, contracts and validation | [rclone development](development/development.md) |
| Developers: ciphertext mapping, resource lifetime and verified saves | [LocalCrypt data flow](development/localcrypt.md) |
| Developers: online browsing, identity and cancellation | [Read-only remote browsing](development/remote-browsing.md) |
