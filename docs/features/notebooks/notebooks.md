# Notebooks

Create and edit native reMarkable ink in local notebook copies.

Notebooks open through the shared document chooser or `.rmdoc` file activation
on desktop, Android and iOS; they have no separate navigation destination.
Save retains editable Logistics page templates. Export Copy (mobile: Export
.rmdoc) produces a separate portable copy, embedding custom backgrounds as fixed
vector PDF pages while retaining native handwriting.

Format support remains experimental. Historical software checks do not complete
the remaining platform responsiveness, native mobile or physical tablet
acceptance gates described in the developer guide.
