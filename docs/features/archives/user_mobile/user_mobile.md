# Archives on mobile

The desktop Archive manager has no mobile workspace or Archives feature toggle.
iOS and Android do not expose its general ZIP/TAR contents browser, source basket,
archive creation, extraction, ZIP add/remove or integrity-check controls.
Use the [desktop Archive manager](../user/user.md) for those workflows.

Mobile can read supported book and comic containers through its dedicated readers.
A ZIP routed to Comics is treated as a comic container, rather than opened in a
general archive manager. The Files **Archive password…** action supplies an inner
archive password for reader access; it does not create or extract archives.

- [Comics on mobile](../../comics/user_mobile/user_mobile.md)
- [Books on mobile](../../books/user_mobile/user_mobile.md)
- [Using Logistics on mobile](../../../user_mobile/user_mobile.md)

These reader workflows do not establish mobile parity for the desktop Archive
manager. No mobile Archive manager acceptance is claimed.
