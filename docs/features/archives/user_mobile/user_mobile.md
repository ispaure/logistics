# Archives on mobile

Open **Workspaces → Local** and browse to your files. Open a file's actions and
choose **Manage archive…** to see its contents. TAR archives also open directly
from File Browser. ZIP and CBZ keep their existing reader action, so use
**Manage archive…** when you want to work with the files inside.

## Create from a selection

1. Open the folder actions and choose **Select items**. Tap the files and folders
   to include, then tap **Create archive…** in the selection bar.
2. Browse to an on-device destination, enter a name, and select ZIP, TAR, TAR.GZ
   or TAR.XZ.
3. Tap **Create here**. If that name is already in use, choose a new name. Keep
   the destination outside the folders you selected.

For one file or folder, **Create archive…** is also available from its own actions.

## Browse, edit and extract

Tap a folder to see its members. Tap a file to select it or use **Select** beside
a folder to select the entire folder. From **Archive actions**:

- Use **Add item…** to select a file or enter the name of a file or folder.
  Additions go at the archive root. ZIP and CBZ support edits.
- Use **Remove selected…** to remove a member or an entire selected folder.
  Logistics verifies the rewrite before replacing the original.
- Use **Extract all…** or **Extract selected…**, choose a destination, and enter
  a name for the new output folder. Existing files and folders are kept.
  Cancel to stop before publication.

The manager validates archive paths and refuses unsafe or colliding entries.
It browses ZIP, CBZ, TAR, TAR.GZ/TGZ, TAR.BZ2/TBZ2 and TAR.XZ/TXZ. Read-only
locations can serve as sources. Creation and extraction require an ordinary
writable on-device destination. LocalCrypt and remote storage continue to use
their existing copy and reader actions. The manager can show encrypted ZIP
member names. Opening protected contents still requires the appropriate
password and runtime support. **Files → Archive password…** continues to supply
the password for the book and comic readers.

## Return to an archive

Use **Documents → Open** to return to the retained archive view. **Close archive**
closes that view. **Recent** reopens a recently managed archive, and **Favourite
archive** adds a shortcut to **Favourites**. If a file was removed outside
Logistics, Recent hides its missing entry and a favourite reports that the
file is unavailable. You can remove that favourite.

Turn **Archives** off in **Settings → Features** after closing the archive
view. This hides the manager and its shortcuts. The archive files and comic
reader settings stay available.
