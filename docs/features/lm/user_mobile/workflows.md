# LM mobile workflows

## Mobile development builds

[Set up Chat](conversations.md) with an OpenAI-compatible server, Apple
Intelligence on eligible iOS devices or Gemini Nano on eligible Android devices.

## Desktop and mobile boundaries

Mobile stores private text chats and drafts, and **Export conversation…** writes
Markdown. For JSON export, file and screenshot attachments, IDE Code mode,
conversation folders and read-aloud, use the [desktop guide](../user/user.md).
Conversation records stay on their own devices.

See the [mobile guide](../../../user_mobile/user_mobile.md) for navigation.
