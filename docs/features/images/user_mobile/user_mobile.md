# Images on mobile

## Image viewer

Open a PNG, JPEG or static WebP from Files or a folder drawer. At fit zoom, swipe left or right for the next or previous image in filename order. Tap to restore controls and use **Fit image** to reset. Images are read-only, up to 8 MiB, 8192 pixels per axis and 16 megapixels. Batch compression and EXIF editing are desktop tools.

## Burst camera on iPhone

1. Open **Home → Burst camera** and allow Camera and Add Photos access.
2. Press **Hold for burst** and release to stop. **Done** closes the camera while accepted photos continue saving as individual images in Photos.
3. Between bursts, use **Camera** and **pictures/s** or **Settings → Camera** to select a lens and request 1–30 pictures per second. The default is 8 and actual capture can be slower.

If Photos saving fails, resolve permissions or space, then manually import the files from **Files → Logistics → Local → Camera Pending**. Leaving the app stops capture. Burst camera is iOS-only.
