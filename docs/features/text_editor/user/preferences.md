# Text Editor preferences

Use **View → Logistics Settings… → Feature settings → Text Editor → Options** for indentation, wrapping, line numbers, whitespace, highlighting and pairing. **Appearance & shared controls → Styling** sets the common code font and size.

Choose personal settings, make edits and click **Save Settings**. Use **↶** to inherit a software default. See [desktop recovery](user.md#appearance-and-preferences) or [mobile editor settings](../user_mobile/user_mobile.md).
