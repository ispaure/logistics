# Books on mobile

Open **Contents and bookmarks** to browse chapters. Tap a chapter title to read
it; tap its chevron separately to expand or collapse nested sections. Rows use
the file browser’s light/dark surfaces, with the current chapter highlighted.
This hierarchy is shared with PDF contents and the documentation browser.

Pinch an EPUB to change its font size and reflow the text within the page.
The saved EPUB font size is independent of Markdown and plain-text sizes.
Opening covers that wrap an archive-local raster image in SVG display that
image; unsupported images show an omission message.
