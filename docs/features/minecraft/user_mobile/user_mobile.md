# Minecraft on mobile

Minecraft server discovery and launch controls are desktop-only. Logistics for
iOS and Android does not provide the Java/Bedrock selector, launch scripts,
server console or Minecraft-specific properties/wiki actions.

These controls are absent from the mobile feature catalog; enabling the desktop
feature does not add them to mobile. General mobile file access is separate from
this integration.
