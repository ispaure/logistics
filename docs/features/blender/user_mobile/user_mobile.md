# Blender on mobile

The Blender installation, preset and addon manager is desktop-only. Logistics
for iOS and Android does not offer a Blender launcher, release installer, preset
editor or addon library.

These controls are absent from the mobile feature catalog; enabling the desktop
feature does not add them to mobile. General mobile file access is separate from
this integration.
