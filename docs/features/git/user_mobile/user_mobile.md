# Git on mobile

The Git workspace is available in Logistics desktop. Logistics Mobile on Android
and iOS does not provide repository opening, clone/init, status, staging, commits,
history, branches, remotes or conflict resolution. There is no Git feature switch
in mobile Settings.

Opening or editing a source file in the mobile Text Editor does not perform Git
staging, commits or synchronization. Use the [desktop Git guide](../user/user.md)
for repository operations.

This describes the current platform boundary; it is not a mobile acceptance
claim. See the [developer guide](../development/development.md) for ownership
and validation scope.
