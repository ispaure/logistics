# Calibre libraries on mobile

Calibre integration is a desktop feature. The native iOS and Android apps do not
provide Calibre library discovery, **Launch Calibre**, or the reviewed Calibre
export dialog. A `metadata.db` file does not turn a mobile folder into a Calibre
workspace.

To read a Calibre book on mobile, export or copy its EPUB on desktop, make it
available through the mobile app's supported storage, then open or import it with
**Books & Comics**. This reads a separate book; it does not synchronize Calibre's
database, metadata or reading progress. Logistics does not convert other book
formats into EPUB during this workflow.
