# Find a feature guide

Choose a tool by the work you want to do. Each link opens that feature's overview,
with routes to its desktop guide, mobile availability and implementation notes.
For the basics of the app itself, begin with the [desktop](../user/user.md) or
[mobile](../user_mobile/user_mobile.md) guide.

Desktop tools are not all available on mobile. The
[platform availability table](../user/features.md) provides a quick comparison;
the individual mobile guides explain supported workflows and limits.
