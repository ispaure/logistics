# Perforce on mobile

Perforce Server is a Linux desktop folder integration. Logistics Mobile on
Android and iOS has no Launch P4D action, P4 console or Perforce feature switch.
Copying `remoteConfig.ini` to a mobile folder does not enable these controls.

Use the [desktop setup guide](../user/user.md) on Linux. Windows and macOS desktop
can expose configured folder controls, but launching and opening the console are
disabled there too.

This describes the current platform boundary; it is not a mobile acceptance
claim. See the [developer guide](../development/development.md) for ownership
and validation scope.
