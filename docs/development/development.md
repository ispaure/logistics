# Developing Logistics

Start with [your first contribution](setup/getting-started.md) to set up the
desktop environment, launch Logistics and check a small change. To change an
existing feature, find it in the [feature catalog](../features/features.md) and
open its Development page.

| I want to… | Start here |
| --- | --- |
| Set up a checkout and run Logistics | [Setup](setup/setup.md) |
| Find or change an app screen, service or document format | [Architecture](architecture/architecture.md) |
| Choose, run or add a test | [Testing](testing/testing.md) |
| Review a build plan, stage the mobile app or prepare a release | [Build and release](build-release/build-release.md) |
| Update a wiki page or verify Help | [Documentation](documentation/documentation.md) |

## Worked lookups

- Follow the [desktop transfer controls](../features/rclone/development/transfers.md#find-desktop-transfer-controls) from the transfer window to its Qt view and progress adapter.
- Use the [screen and panel map](architecture/ui-architecture.md#find-a-screen-by-its-visible-name) to find the desktop and mobile appearance settings owners.
- Open a disposable notebook and follow the [brush walkthrough](../features/notebooks/development/brush-calibration.md#try-a-brush-change) to the pressure catalog, Canvas renderer and focused check.
- Follow the [Build Manager review walkthrough](build-release/build-manager-journeys.md#trace-a-validation-plan) to inspect a local plan and trace it to the Logistics adapter before running it.
