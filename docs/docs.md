# Logistics documentation

Logistics brings file browsing, readers, editors and optional tools into one
workspace. Desktop and mobile share many document workflows, but their navigation
and supported tools differ. Start with the guide for the app you are using.

## Learn to use the app

- **[Desktop guide](user/user.md)** — install and open Logistics, try a local
  document, then learn how folders, workspaces and open documents fit together.
- **[Mobile guide](user_mobile/user_mobile.md)** — open your first document on
  Android or iOS, find it again, and choose where to keep it.

Both guides introduce ordinary local files before connections, encrypted storage
or batch operations. You can explore the app without configuring a server.

## Find a tool or solve a specific task

The **[feature guides](features/features.md)** group tools by what you want to
do: read and edit, organize files, connect storage, or work with other applications.
Each feature has desktop, mobile availability and development guides in the same
documentation tree.

For questions that apply across tools, use the desktop guide's
[storage and recovery](user/working-safely.md),
[configuration](user/configuration.md) and
[reading history](user/reader-history.md) pages, or the mobile guide's
[document workflows](user_mobile/documents/documents.md).

## Contribute to Logistics

The **[developer guide](development/development.md)** starts with running a
checkout and understanding the application, then explains how to make and check
a change. Architecture references, feature contracts, test commands and release
procedures are available when you need them.

If you already have a checkout and are preparing an installable app or a release,
go to **[Build and release](development/build-release/build-release.md)**.
