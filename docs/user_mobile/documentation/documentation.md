# Using documentation

Open **Settings → Help → Mobile documentation** to read the bundled guides offline.

## Browse folders and pages

Tap the hamburger to show or hide the tree in a narrow window. Wider windows
show the tree beside the page. Tap a folder's chevron to expand it or its name
to open its guide. The current page, search, and expanded folders survive
layout changes.

## Back, Forward and Up

Use **‹ / ›** to revisit pages and **••• → Parent folder page** to go up.
Choose **Find in this page** to search the open article. **×** closes Help and
returns to the opening screen. Android Back closes the tree first, then
follows page history and leaves Help at the first page.

## Search in the window

Enter a query in **Search documentation** and choose **File names & titles**
or **Page text**. Results retain their parent folders. Clear the query to
restore the full tree.

## Relative links and text files

Relative links open bundled Markdown pages and folder guides within Help.
Local `.txt` and `.py` links open a separate text editor session. Return to
Help through Settings. Links support Markdown and wiki aliases.

## Reading formatted pages

Swipe wide tables horizontally. Local heading links jump within the page.
External links are inert, and scripts and remote resources are blocked.
