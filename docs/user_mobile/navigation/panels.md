# Mobile panels

On a compact screen, the bottom tabs name the destinations. Wide Android
windows show a left rail. Long-press an icon to see its label. On iPhone Duo,
the fold can separate a list from its details. Resizing keeps the current
destination and collection.

## Choose a destination

- **Home** starts a document and gives quick access to an open file,
  favourites and a recent file.
- **Workspaces** opens folders, connections and transfers. Use
  [Workspaces](../folder_hub/folder_hub.md) to choose a source and review
  transfers.
- **Documents** shows open, recent and saved files and gives access to
  favourites and libraries. See [Documents and readers](../documents/documents.md)
  for returning to a file.
- **Chat** shows conversations and drafts. If Send is disabled, use
  **Set up chat** to choose a server and model.
- **Settings** changes features, appearance and privacy. In a wide
  window, options can stay open beside the category list. See [mobile
  settings](../settings/settings.md).

## Find the controls in a narrow panel

Use **…** for actions, **×** to close a document, and the magnifying glass
for search in a list or Find in a document. Open file information to read a
shortened filename in full. In a reader, chevrons step through pages or
matches. Manga mode reverses the page arrows. Drag and release the comic
page slider to jump.

If you leave a running transfer to browse ordinary files, tap the transfer
indicator to return to its progress. On iOS and Android, **Settings →
Workspaces → Show Legacy** reveals legacy folders and credential names until
the next launch.
