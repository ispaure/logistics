# Mobile panels

## Using the mobile panels

- **Home** opens or creates files and shows recent documents.
- **Documents** switches between Libraries, Favourites, Open, Recent and Saved.
  Tap a filename to resume or **×** to close it through the unsaved-change
  prompt. **Search documents** finds local filenames.
- **Workspaces** opens folders, connections and transfers. See
  [Workspaces](../folder_hub/folder_hub.md) for source selection and transfer review.
- **Chat** opens conversations. If Send is disabled, use **Set up chat** to select
  a server and model.
- **Settings** changes features, appearance and privacy. See
  [Mobile settings](../settings/settings.md).

## Panel layout

Compact windows use labeled bottom navigation. Wide Android windows show a
left rail. Long-press an icon for its label. On iPhone Duo the fold can separate
a list from its details. Resizing keeps the current destination and collection.
See [Mobile navigation](navigation.md) for toolbars and fold behavior.

## Credential groups, open documents and privacy

Use **Credential** in Workspaces to show all packages or a single package.
Unlocking a password-protected session-only package restores its encrypted open
and recent references. Locking hides them again. An ordinary Local copy remains
a readable file.

Use **Clear** beside **Recent** to remove recent links, including encrypted
history for unlocked packages. Open documents and saved files remain.
**Forget saved credentials** removes retained credential packages.

## Focused browsing and setup

**Parent folder** moves up one folder. **Back** leaves the screen or returns to
the reader after closing a tool panel. Open file information to see a shortened
filename in full. Transfers can continue while you browse ordinary local files.
Tap the transfer indicator to check progress.

### Compact mobile control icons

Use **…** for actions, **×** to close a document, and the magnifying glass for
search or text Find. Chevrons step through pages or matches. Manga mode reverses
the page arrows. Drag and release the comic page slider to jump.

### Current iOS and Android differences

iPad supports additional app windows. Android offers **High contrast / E Ink**.
Both platforms offer **Settings → Workspaces → Show Legacy** to reveal legacy
folders and credential names until the next launch. See
[screen privacy](../settings/settings.md#screen-privacy-and-platform-limits)
for each platform's capture behavior.

### Android fullscreen comics and developer settings

Tap a fullscreen comic to restore its controls. An edge swipe can temporarily
show system bars. **Settings → Help → More → Android Developer Settings…**
opens system developer options once developer mode is enabled.
