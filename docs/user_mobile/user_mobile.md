# Logistics on mobile

Start with [Getting started](getting_started/getting_started.md) or
[Documents and readers](documents/documents.md). Open **Settings → Help →
Mobile documentation** to browse or search the offline
[guides](documentation/documentation.md).

## Installing Android test builds

Accept your Firebase App Distribution invitation with your Google account,
download the APK, and allow installation from that source. Keep the existing
beta installed to preserve its data. Debug-signed builds have a separate
signing identity. See the [Build Deployment Manager guide](../user/build-manager.md).

## Direct remote reading

Tap a supported file in Workspaces or Remote files. See
[Remote and offline files](documents/remote.md#direct-reading) for limits and
copying files for offline use.
