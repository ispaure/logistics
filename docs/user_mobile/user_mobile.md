# Logistics on mobile

Start by [creating, saving and reopening a note](getting_started/getting_started.md).
You can do it on the device before connecting to other storage. Use **Home**
to start a document, **Workspaces** to see the folders that hold your files,
and **Documents** to return to open readers and editors.

## Keep working with your files

Use [Documents and readers](documents/documents.md) to find saved files, switch
between open documents, and work with drafts. To browse a folder or connect to
another location, open [Workspaces](folder_hub/folder_hub.md). Its storage guide
explains which folders you can edit, keep offline or access over a connection.

[Mobile navigation](navigation/navigation.md) covers tab behavior, drawers and
multiple windows. [Mobile settings](settings/settings.md) covers appearance,
restoration, storage and privacy. Read [Using documentation](documentation/documentation.md)
for browsing and searching this guide offline from **Settings → Help → Mobile
documentation**.
