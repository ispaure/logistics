# Remote and offline files

Configure remote connections from Settings → rclone / Remote connections. Browse a
connection from Folder Hub or Remote files, then tap a supported document.

## Direct reading

Direct remote readers support small text and Markdown, INI, PNG/JPEG/WebP images,
EPUB books and CBZ/ZIP comics within their reader limits. Unsupported or oversized
files show an explanation. The app does not download an offline copy automatically.
The folder search filters the currently displayed folder.

A direct reader is read-only: it has no Save, Save As or metadata-edit controls.
Locking or replacing credentials retires associated private reader contents.

## Offline folders

Use Folder Hub's managed Pull workflow to keep files in a Local or LocalCrypt
folder. Review the proposed transfer before applying it. Existing offline copies
remain readable and exportable when the remote is unavailable.

A retained book/comic import, a managed folder and a temporary remote preview are
different kinds of storage. Settings → Saved books & comics reports retained reader
imports; it does not count managed folders or previews held only in memory.
