# Documents and readers

Opening a file puts a reader or editor in **Documents** while the file
itself stays in its folder. To try this with a file you create yourself,
start with the [first-use walkthrough](../getting_started/getting_started.md).
Use the storage row beneath a document's title to check where the file
lives, whether its source is locked and whether it is read-only.

## Return to something you opened

**Recent** in Documents lists up to 20 items, including open files and files you can reopen. Open
entries keep their current reader or editor, including unsaved edits, and show
an **Open** badge. Use their close control to close a view. Home previews up to
three recent items, and **See all** opens Recent in Documents. Filenames on both
screens can wrap to two lines.

**Libraries** shows available Notes, Comics and
[Books](../../features/books/user_mobile/library.md) libraries. Use the shortcuts
under **Your libraries** on Home to go straight to Notes, Books or Comics.
Select **Libraries** again to see every library. **Saved files** lists
app-managed text files and notebooks outside Recent. Library rows show their
names, with a caption for encrypted libraries. A storage icon and caption
identify the source beneath individual file names. Home, Favourites and Recent
show thumbnails for supported local files.
When a saved credential ZIP can be unlocked, Documents shows the Unlock
button and a hint above Libraries, Favourites and Recent. Unlocking all
available ZIPs removes both.
In a wide window, Documents keeps its libraries and document lists on the left.
Select a Books or Comics library to browse its files. Use the folder toolbar to
search, switch between tiles and rows, or select items for available file actions.
Back to a parent folder keeps the current layout. The selected library stays on
the left when there is room for both panes. Rotating keeps the current folder,
including any subfolder. Select a Notes library to open its Notes Library view.
Tap a favourite or recent file card to open it directly. Tap its three-dot button for file actions.
If a Recent entry fails, find the file in its current folder,
reconnect its remote, or unlock its credential.

## Find the file in its folder

Browse to a file in [Workspaces](../folder_hub/folder_hub.md). In
Documents, **Search documents** finds
on-device filenames and folders, including files you have never opened and
files in unlocked LocalCrypt copies. Search checks cached matches first and
shows those it verifies on storage. It then checks for new files and adds
matches as it finds them. The status shows the current location, phase, and
how many names have been checked in that location during the current pass.
Search reports locations it could not access. Tap **×** to leave search.
Search opens in its own panel with one **×** control. Tap a file to open it;
closing the reader returns to the same populated results. Supported files
show thumbnails, and **…** beside a result opens its actions. Tap a matching
folder to browse it and its subfolders with File Browser actions and List or
Tiles. Back retraces those visits to the search, where results remain available
and an unfinished scan continues. **×** returns to the collection or original
folder. In Workspaces, the local subtabs also offer search before
selecting a folder: **On My Phone/Tablet** searches device files, while
**Rclone copies** searches available local copies, including unlocked copies.
If a Markdown result belongs to a Notes Library, choose **Open in Notes Library**
or **Open in Regular Viewer**. An **Always Open** option remembers the choice for
future results. Change or reset it under **Settings → Markdown → Notes Library
files from search**.

EPUBs, comics, PDFs and videos show their reading or playback percentage on
document cards, above the File Browser row menu and in the upper-right of tiles.
**0%** is gray, progress is blue, and **100%** is green. Use the file's action
menu to mark a document read or unread, or a video watched or unwatched.
Marking an item read or watched keeps your saved place. When you reopen a
document or resume playback, the percentage follows the displayed page or
playback position again. Marking an item unread or unwatched resets its
position to the start. Built-in help stays out of Recent.

From a document with a browsable source, choose
**••• → Show in folder** to select it in Workspaces. The document remains
open. For a locked source, use **Unlock LocalCrypt** on Home, Workspaces
or Documents before browsing its files.

## Text and Markdown

Choose **New document** and select plain text, Markdown or a reMarkable
document. Name the file, choose a writable location, and tap **Create here**.
You can create a subfolder with **New folder**. For notebooks and templates,
see [Notebooks on mobile](../../features/notebooks/user_mobile/user_mobile.md).
If the picker shows a named copy or encrypted copy, check [how those
locations work](remote.md) before choosing it.

Existing Markdown opens in preview. Tap **Edit Markdown** to work in
**Formatted** or **Source**. Both edit the same draft. New Markdown files
start in edit mode. Use Source above 1 MiB. In the text and source editors
you can choose a language and see logical line numbers. Syntax highlighting
pauses above 128 Ki characters. See [images in folder-backed
Markdown](../../features/text_editor/user_mobile/user_mobile.md#images-in-folder-backed-markdown)
when adding an image from the same folder.

## Save As and closing

For an editable folder-backed document, **Save** writes to the file in its
current location. Use **Save As** to choose a destination for a copy. If you
cancel the picker, you return to the same draft. To close the document, tap
**×**. If it has unsaved edits, choose **Save**, **Quit without saving**
or **Cancel**. A failed save keeps the draft open.

See [document workflows](workflows.md) for making copies, moving open files
and recovering a draft after a failed save or restart. Use [Reading and editing on mobile](reading-and-editing.md) for reader
controls and read-aloud. [Remote and offline files](remote.md) explains
which locations you can save to and where a copy goes.

## Favourite files

Open the document and use its menu to add it to Favourites. The shortcut
appears in **Documents → Favourites** and restores the context
the document was opened in. A note favourited from Notes Library reopens
there. Home previews two favourites. Tap **See all** for the full list.
To remove a shortcut from the list, use the row’s **… → Remove from
Favourites** in **Documents → Favourites**. Session-only favourites appear
after you unlock the matching credential.

## Send a file to another app

Choose **Send to App…** in the file’s item menu, then choose a destination in
the iOS or Android share sheet. Logistics shares the selected file’s saved
contents. Save any edits you want to include before sharing. If the file is
in protected storage, approve the readable copy before choosing the destination.
You can dismiss the share sheet to cancel. On Android, open the file in the
destination within 15 minutes. A destination can keep its own copy.
